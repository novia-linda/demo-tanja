Bra att veta före testningen

1. Basic är inte “utan Copilot”.
Copilot Chat utan tilläggslicens har web-grounded chat, filuppladdning och bildgenerering, men med standard access. Betald Microsoft Copilot ger priority access och Work IQ över arbetsdata.
2. Gratis agent = främst instruktioner + offentlig webb.
Microsoft anger att deklarativa agenter som bygger på instruktioner och publika webbplatser kan användas utan extra licenskostnad. Delad tenantdata som SharePoint kan kräva Copilot-licens eller metered usage/PAYG.
3. Agent Builder har andra filgränser än vanlig chatt.
I Agent Builder dokumenteras bl.a. upp till 4 publika webb-URL:er och upp till 20 direkt uppladdade embedded files. Det är alltså inte samma sak som din observerade gräns på tre filer i en vanlig chatprompt.
4. Webbkälla betyder inte alltid live-läsning.
Scoped web search använder Bing-indexerat innehåll. Dynamiska/client-renderade sidor kan därför bli ofullständiga eller gamla.
5. “Only use specified sources” är inte en hård brandvägg.
Microsoft skriver att Agent Builder kan prioritera angivna källor men inte fullständigt blockera modellens allmänna kunskap.
6. Behörigheter följer användaren.
En agent ska inte ge en mottagare SharePoint-information som mottagaren saknar rätt till. Däremot kan delning och licens/metering avgöra om retrieval över huvud taget fungerar.
